# 에이전트 출고 집계

서버 기동 후 `DailyShipmentArchive`가 `db/init/item_event_daily.sql`을 적용한다.
기존 시연 DB의 `item_event_daily`와 규격·상품 참조는 보존하고, 집계가 없는 DB에서도 원본으로 동작한다.

`/internal/v1/warehouses/{id}` 아래 상품별 출고, 박스 사용, 월별 출고, 출고 상태 조회는
`agent_shipment_history`를 사용한다.

- 과거 날짜에 집계가 있으면 그 집계를 사용한다. 보관 중인 같은 날짜 원본은 다시 세지 않는다.
- 집계가 없는 날짜는 원본을 사용한다. 오늘은 원본을 읽어 신규 출고를 즉시 반영한다.
- `live-` 시연 출고와 아직 도래하지 않은 출고 시각은 에이전트 운영 실적에서 제외한다.
- 박스 사용 충진율은 집계의 충진율 합계를 출고 수로 나눈 가중 평균이다.
- 출고 상태의 마지막 시각은 원본이 있는 마지막 날의 실제 시각을 유지한다.

매일 한국 시각 00:15에 전날 원본이 남아 있는 센터를 집계한다.
DB advisory lock으로 여러 서버의 동시 집계를 막고, 원본이 없는 센터·날짜의 집계는 보존한다.
원본 삭제는 하지 않는다. 거제의 전체 비교 시뮬레이션 이력도 유지된다.
일정은 `chagok.shipments.archive-cron`으로 조정할 수 있다.

기존 main의 대시보드·실시간 출고 API는 변경하지 않는다.
배포 시 서버를 먼저 올린 뒤 에이전트와 client를 배포한다.
